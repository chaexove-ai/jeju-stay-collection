# Jeju Stay Collection

**제주 숙소 15곳을 소개하는 상업용 사이트** — [jejustaycollection.com](https://www.jejustaycollection.com)
*A live bilingual site for 15 stays on Jeju Island — a Google Sheet in, 32 static pages out.*

**실행:** `npm run build:fixture` — 구글 시트 접근 없이 전체가 빌드됩니다

---

## 무엇을 만든 것인가

제주 숙소 마케팅 대행사의 실제 운영 사이트입니다. 구글 광고로 홍콩·대만·싱가포르에서
방문자를 데려오고, 사이트는 열다섯 곳을 소개한 뒤 각 숙소의 예약 페이지로 넘깁니다.

요구사항의 핵심은 하나였습니다. **빨리 비켜줄 것.** 광고와 예약 페이지 사이에 클릭이
하나 늘 때마다 사람이 빠지므로, 체류 시간이 아니라 이탈 속도를 기준으로 설계했습니다.
가격은 일부러 넣지 않았습니다. 변동이 잦아 정확히 따라가기 어렵고, 틀린 가격은 없는
가격보다 나쁩니다.

영어와 번체 중국어로, 32개 정적 페이지가 나갑니다.

## 내가 한 것

기획·디자인·구현을 모두 맡았습니다. 설명이 필요한 지점은 다음과 같습니다.

**스프레드시트가 CMS입니다.** 대행사는 구글 시트에서 숙소를 고칩니다. 빌드는 그 시트를
CSV로 한 번 읽고 정적 HTML을 씁니다. 시트에 붙인 앱스스크립트가 Vercel 배포 훅을 때려
셀을 고치면 사이트가 다시 배포됩니다. 아무도 관리자 화면을 배우지 않아도 되고, 살려둘
데이터베이스도 없습니다.

**빈 사이트를 내보내느니 빌드를 실패시킵니다.** 시트를 못 읽거나 숙소가 다섯 곳 미만으로
파싱되면 빌드가 죽습니다. Vercel은 실패한 빌드를 배포하지 않으므로 직전 배포가 그대로
살아 있습니다. 시트가 깨지는 것은 비용이 들지 않지만, 숙소가 0개인 사이트가 조용히
나가는 것은 대행사에 실제 손해입니다.

**프레임워크도, 타일 서버도 쓰지 않습니다.** 사이트 전체가 1,000줄짜리 Node 스크립트
하나입니다. 지도는 해안선과 읍·면 경계 좌표를 소스에 담아 직접 그립니다. 쓰던 타일
제공자가 예고 없이 API 키를 요구하기 시작한 뒤 내린 결정입니다. 운영 중인 상업
사이트에서 지도가 갑자기 죽는 위험을 남겨둘 수 없었습니다. 지역명 라벨은 숙소가 있는
읍·면에만 답니다.

**렌더러 하나가 두 환경에서 돕니다.** `src/render.js`는 문자열만 만들고 DOM을 건드리지
않습니다. 빌드는 이 파일을 `new Function`으로 불러 서버 렌더링에 쓰고, 브라우저는 같은
파일을 그대로 받아 필터링에 씁니다. 그래서 양쪽 마크업이 어긋날 수 없습니다.

**데이터를 의심합니다.** 위경도는 제주 범위 안에 있을 때만 받아들이고, 뒤집힌 값은 한 번
구제한 뒤 그래도 벗어나면 버립니다. 바다 한가운데 점을 찍는 것보다 낫습니다. 문구에
들어가는 숫자("열다섯 곳")는 글자로 박지 않고 빌드가 채우는 함수로 둡니다. 열여섯 번째
집이 들어오는 날 사이트가 조용히 거짓말을 하지 않게 하기 위해서입니다.

**점검을 실행할 수 있게 만들어 뒀습니다.** Playwright 스크립트 세 개가 `dist/`를 로컬에
띄우고 외부 요청을 전부 막은 채 훑습니다.

| | |
|---|---|
| `verify.mjs` | 고쳐둔 것이 그대로인가 |
| `audit.mjs` | 아직 못 본 것은 없는가 — 32페이지 전부, 링크·메타·중복 id·콘솔 오류 |
| `a11y.mjs` | 실제로 화면에 그려진 색으로 잰 대비와 손가락 자리 |

## 실행 방법

```bash
npm install
npm run build:fixture    # fixture.csv로 빌드 — 시트 접근 불필요
```

결과는 `dist/`에 나옵니다. 아무 정적 서버로나 띄우면 됩니다.

실제 시트로 빌드하려면 (시트가 "링크가 있는 모든 사용자 · 뷰어"여야 합니다):

```bash
npm run build
```

빌드 후 점검:

```bash
node verify.mjs
node audit.mjs
node a11y.mjs
```

## 구성

```
build.mjs          정적 빌드 전체 — 시트가 들어가고 32페이지가 나온다
src/data.mjs       CSV 파싱, 검증, 좌표 온전성 확인
src/render.js      공용 렌더러 (Node와 브라우저 양쪽에서 실행)
src/i18n.mjs       두 언어의 문구·태그·배지
src/jeju.mjs       해안선과 읍·면 경계 좌표
src/legal.mjs      개인정보처리방침, 사업자 정보
src/theme.css      디자인 토큰
ogcard.mjs         1200×630 공유 카드 생성
verify.mjs / audit.mjs / a11y.mjs    Playwright 점검
fixture.csv        시트 없이 빌드하기 위한 샘플 데이터
```

## 메모

- 공유 이미지는 특정 숙소 사진이 아니라 컬렉션 전체를 보여줍니다. 한 곳의 사진을 쓰면 그
  숙소만 공짜 노출을 가져갑니다.
- og 이미지는 빌드 때 만들지 않고 따로 만들어 커밋합니다. Vercel 빌드에 크로미움을 얹지
  않기 위해서이고, 사진도 숫자도 없어 숙소가 바뀌어도 틀리지 않습니다.
